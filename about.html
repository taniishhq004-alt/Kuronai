About Kuronai

Theme: Mint Green + Midnight Blue. This project includes:

  • Frosted glass UI & responsive layout
  • Fetches real-time answers for “who is” and “what is” questions using live Wikipedia search.
  • Solves mathematical expressions instantly using an online calculation API.
  • Voice input & speech output

Open chatbot.html to test. The JS file is in app.js and is well-commented to help you extend features (APIs, models, storage).
