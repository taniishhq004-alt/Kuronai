# 🤖 Jaat – Voice Enabled Smart Chatbot

A modern web-based chatbot with voice input/output, smart replies, Wikipedia integration, Math solving capability, and Firebase chat storage.

---

## 🚀 Features

- Smart keyword-based replies
- Wikipedia API integration
- Math solving support
- Voice input & output
- Firebase chat storage
- Clear conversation feature
- Glassmorphism UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Firebase Firestore
- Web Speech API
- Wikipedia API
